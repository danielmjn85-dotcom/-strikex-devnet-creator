STRIKEX Devnet Creator

Qué hace:
- Conecta Phantom desde el navegador de Phantom o un navegador con extensión compatible.
- Usa Solana Devnet.
- Crea un mint SPL con 9 decimales.
- Acuña 1.000.000.000 SKX a la wallet conectada.
- Revoca mint authority y freeze authority.
- Muestra mint y firma de transacción.

Importante:
- Es SOLO para Devnet.
- No usa dinero real.
- No incluye metadata on-chain de nombre/logo todavía.
- No incluye liquidez, DEX, presale ni mainnet.
- Nunca introduzcas tu seed phrase o private key en esta web.

Publicación:
- Puede alojarse como web estática en GitHub Pages, Cloudflare Pages o Netlify.
- Para Phantom móvil, abre la URL publicada desde el navegador interno de Phantom.
